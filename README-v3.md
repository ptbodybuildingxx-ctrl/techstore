# TechStore PWA 3.0 – لوحة التحكم بالمتجر

نسخة تجريبية محلية مبنية على الإصدار 2.0. لا تتضمن خادماً أو مصادقة فعلية. لا تستخدم بيانات حقيقية أو تنشرها باعتبارها متجرًا تجاريًا آمناً.

## التشغيل
- فك ضغط المشروع، ثم افتح مجلد techstore-v3 وشغّل `python -m http.server 8080`.
- افتح `http://localhost:8080` في متصفح حديث. على الهاتف يلزم HTTPS للتثبيت. ملفات manifest وservice worker موجودة.
- من لوحة الإدارة، اختر «مدير» من قائمة الدور ثم «التحكم بالموقع».
- زر «واجهة المتجر» يعرض نتيجة التعديلات. عد إلى «لوحة الإدارة» لتعديلها.
- ملف المعاينة المستقل HTML مناسب للتجربة المحلية (لا يدعم تثبيت PWA عند فتحه كملف).

## لوحة المالك
1. الهوية: الاسم، الشعار (PNG/JPEG/WebP حتى 350 KB)، الألوان، واتساب، العنوان، ساعات الدوام.
2. المحتوى: عنوان ووصف وإعلان الصفحة الرئيسية بالعربية والإنكليزية؛ إضافة صفحات نصية وتعديلها ونشرها وإخفاؤها وحذفها.
3. عرض المنتجات: الصور، الوصف، الاسم الإنكليزي، الإخفاء من المتجر مع بقاء المخزون، المنتجات المميزة، تعديل أسعار البيع دفعة واحدة بنسبة مئوية. أسعار الفواتير السابقة لا تتغير.
4. الأقسام والتصنيفات: إظهار/إخفاء الأقسام الاختيارية، إعادة تسمية التصنيفات الأساسية وإخفاؤها، وضع الصيانة.
5. الطلبات والدفع: تحديد طرق الاستلام (من المحل/توصيل) والدفع (عند الاستلام/تحويل يدوي). ليست بوابة دفع.
6. الصلاحيات: تخصيص الأقسام المرئية لكل دور تجريبي. لا توجد مصادقة أو صلاحيات خادم؛ يمكن تبديل الدور من الواجهة.
7. سجل التعديلات: آخر 300 تعديل داخل لوحة المالك، محلي وقابل للتغيير؛ ليس سجل تدقيق أمني.

## البيانات
تستخدم النسخة نفس مفتاح التخزين المحلي للإصدار السابق على نفس أصل الموقع. استخدم «الإعدادات والنسخ» لتصدير JSON قبل الترقية أو استعادة نسخة. تختلف مساحة التخزين حسب المتصفح، ورفع صور كثيرة قد يملؤها. لا يوجد مزامنة بين الأجهزة. لا يمكن حماية البيانات أو الدفع الحقيقي من دون خادم آمن، قاعدة بيانات، مصادقة وصلاحيات على الخادم، وتكامل مزودي الدفع والإشعارات.

## الاختبارات
تم فحص صياغة JavaScript وتشغيل اختبارات منطقية في Node باستخدام DOM وهمي: تحميل بيانات العينة، أقسام لوحة المالك، تغيير نصوص الواجهة، إخفاء المنتجات والأقسام، الصفحات المنشورة، الصيانة، قوائم الأدوار وطرق الطلب. لم يتم اختبار تفاعلات المتصفح كاملة أو اعتماد أمان الإنتاج.
