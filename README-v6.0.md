# TechStore 6.0 Business Pro — first integrated release

New invoices atomically post balanced revenue and payment pairs, and register warranty periods. Subsequent receipts are linked to an invoice, have stable request IDs and reject overpayment. Owner can record a cash contribution/operating expense and close the current UTC day with counted cash and variance. Ledger balance is cumulative book cash; it does not adjust automatically for counted differences. New invoice issuance and this ledger's mutations stop after closing until next UTC day. Existing POS/branch/legacy accounting routes are separate and are not blocked by this close. No tax, COGS, supplier accounting, consolidated ledger, refund or installment sale engine yet. Do not double-enter transactions or count old tills as new ledger cash. No historical backfill (zero existing invoices when verified).

Owner sets invoice logo and manual SYP-per-USD display rate; snapshotted on new invoice. Accounting and payments remain USD. Original invoice is immutable; current-balance preview includes later receipts. Receipt print, A4/A5/80mm CSS print options and repair intake print from existing ticket data. Browser/printer support and actual thermal output not verified. New invoice warranties are in separate automatically linked register; legacy warranties retained. Repair intake uses existing notes, not a new inspection or legally binding form.

Security: new tables RLS and no direct public/authenticated access. RPC checks active session and role, customer invoice ownership; finance list admin only, technician warranties only repair. SQL rollback test passed invoice ledger, warranty, rate snapshot, idempotent receipt, overpayment denial, close and anonymous access denial. JavaScript syntax checked; authenticated browser issuance, printer and end-to-end workflow remain untested. No existing records removed. No Edge redeployment. Existing pending public catalog metadata, legacy order bypass, MFA, leaked-password protection, pg_net extension warning, external backup/restore, full offline, product Storage and external provider integrations remain. Not a production security certification.
