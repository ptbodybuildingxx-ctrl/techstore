# TechStore 5.4 — Catalog editor

Owner product management adds category-specific spec fields, custom brand/category/model, variant labels, description, up to four compressed JPEG photos, validated YouTube links, product preview, duplication with fresh SKU and zero initial quantity, bulk hide/publish/price/brand/category operations (50 selected rows), and expanded CSV import (500 new drafts). Existing products, stock and accounts are preserved. New products and CSV imports default to hidden drafts; choose Published or bulk publish. Each variant has independent SKU and stock, grouped by same brand/model/type when public metadata is available. Wholesale still uses configured membership discounts, not separate per-SKU wholesale prices. Reuse existing model specs from your catalog; no external automatic specification lookup.

Images remain in existing revision-checked workspace snapshots: compressed up to 100k characters per image, max four; saves stop at 7.6MB request body to avoid server limit. This is not scalable object storage. Link video instead of uploading video. Only approved YouTube link formats accepted; no embeds. Product details UI reads public metadata when available. Existing server returns only one image and basic fields. Proposed server source is saved under docs/pending-edge/techstore-api-5.4.ts because deployment was blocked. The live server remains 5.3. Do not assume public galleries, metadata and variant switching work until proposed API is reviewed, deployed and tested. Admin metadata uses existing state API, revision conflict check, and owner-only access. No schema or live data changes.

Syntax and pure-function tests passed CSV metadata, structured specs, invalid/duplicate fields, video allowlist, gallery sanitization, and bulk price changes preserving cost and qty. Added tests to CI; authenticated browser end-to-end, actual image upload and live admin save remain unverified. Security review of proposed API required before deployment.
