# TechStore 6.1 — invoice settlements
Owner-only installment sales to linked customer accounts: down payment, 1–36 monthly installments, first due date, no interest. Server verifies price and stock, creates the existing invoice and ledger entries, and creates an exact-cent schedule. Subsequent receipts are allocated oldest-first. Customer and staff can see authorized schedules (latest query limited to 500 rows ordered by due date). No automated reminders or lending compliance review.
Owner-only full cash sale refund for invoices fully paid in the new ledger, with explicit inspection confirmation. All goods must be resalable. Original invoice remains immutable, refund note is printable, stock restored at weighted cost using original sale item costs, revenue and COGS reversed, cash debited through reversal, linked warranties marked cancelled. Refund denied on closed day, insufficient recorded cash, missing product/cost, existing refund or legacy return, and installment invoices. Legacy returns for these invoices blocked by database trigger. Legacy report records profit adjustment as expense; legacy gross revenue remains unadjusted. No partial refunds, damaged inventory handling or installment cancellation.
No real payment or product changed by rollback tests. SQL test passed exact schedule allocation, customer access, refund idempotency, inventory restoration, net revenue and cost, customer refund denial. JS syntax and markup smoke checks passed. No real browser or physical printing verification. Existing security warnings remain; no certification of production readiness.
