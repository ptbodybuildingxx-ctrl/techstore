# TechStore 6.3.9 — Release candidate

Shop repository only. No SaaS changes, new sections or settings changes.

## Fixes
- Offline vault: a save captures its expected encrypted revision before awaiting encryption, refuses stale or locked saves, and never restores a locked vault into memory. IndexedDB opening can be retried after errors and blocked upgrades.
- All supported online financial request scopes now require a durable confirmation ID, including callers that omit one.
- Database offline sync enforces stock-read permission for staff and inventory read/write for stock-count staff, and rejects missing action/kind.
- Four new JavaScript regression tests passed against the exact source with simulated persistence/network. A rollback database test verified stock permission denial, missing kind rejection, repeated receipt identity and last-item conflict; it did not test simultaneous physical devices.
- Public browser smoke test on the previous published 6.3.8 passed page rendering, public navigation/catalog and automatic/desktop/mobile display selector. No credentials or transactions were used.

## Open release gates
- Review remaining legacy Edge routes and all employee/customer permission combinations.
- Security advisor: two warnings remain (pg_net in public, leaked password protection); no admin ownership or paid upgrade authorized. See RECOVERY.md.
- Complete backup and isolated restore. No production restore, data deletion, or new paid environment.
- True concurrent multi-device checkout, real MFA, authenticated desktop/mobile operations, invoice printing/barcode scanner, physical cash and stock matching.
- Full Node 24 suite and GitHub Actions, and final live 6.3.9 verification. The public browser check above does not prove deployment of this version.
- No final commercial approval until these gates pass. Historical 15 reconciliation tests remain evidence of prior integration, not a new physical inventory audit.
