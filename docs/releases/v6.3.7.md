# TechStore 6.3.7 — Integrated ledger, loyalty and permissions

## Applied
- Legacy authenticated Edge reads use the protected workspace RPC. Legacy debt and installment writes now use a transactional ledger RPC with request-id replay protection.
- Standalone debt opening balances are separated from sales revenue. Payments update the existing record, ledger and audit together; overpayments and payments against closed cash days are rejected. Historical openings without ledger links require review rather than automatic backfill.
- The existing business screen includes standalone receivables/payables and 15 reconciliation checks, including new central stock change history, stock chain, and recorded cash closing differences.
- Installment loyalty accrues on collected payments and reverses on cancellation. Existing linked cash invoices can redeem points at an owner-configured limit; partial returns restore points proportionately. The existing owner limit remains unchanged (0% at verification). Branch linked-sale loyalty remains compatible.
- Individual read restrictions extend to specialized registers. No new navigation sections, account deletions or destructive data migration.
- The three deployed Edge function source files were checked against GitHub: API v4, AI v2, push v1 (ACTIVE).

## Verified using rollback database tests
- Debt opening, payment, replay, and installment balance reconciliation.
- Installment down payment, subsequent receipt replay, cancellation, POS redemption quote/issue/replay, partial return and linked branch sale.
- Owner, cashier, stock, technician and customer permissions on tested paths, customer isolation, denial of invalid session, and anonymous finance execution denial.
- Single-unit invoice and retry produce one invoice; a second distinct request is rejected when stock runs out. Central stock history and chain reconcile. Mandatory owner MFA denies a simulated AAL1 session.
- These are database simulations, not a real simultaneous two-device load test or a real authenticator enrollment.
