# TechStore 6.3.4 — owner-controlled optional MFA

No new navigation section. Existing account settings contain authenticator enrollment (manual TOTP setup key), code verification, removal and an owner-only policy selector. Default optional; no factor enrollment or mandatory mode applied to existing accounts. Optional mode allows self-enrollment; enrolled verified factors still require verification on subsequent login. Owner can require admins or all staff, but only in a verified AAL2 session. Customers are not covered by mandatory staff policy. Removing the last verified factor via the UI is blocked while that account is subject to mandatory policy. Supabase Auth controls enrollment and verification availability; ensure TOTP is enabled and verify recovery with a backup authenticator before enforcing any policy.

Database checks active session, verified factor, session AAL2 and signed JWT aal2 for existing live_session-backed RLS/RPCs. Legacy Edge session validation checks the actual server session's AAL2, but the old Edge endpoints pass only session ID and user ID, not the JWT AAL claim. They therefore cannot distinguish a pre-verification JWT for an already elevated session; full token-level enforcement requires a reviewed Edge release. Offline vault remains separate; it cannot enforce newly changed online policy until reconnect. Auth-managed recovery and other legacy routes need end-to-end verification. No new secret stored in the workspace, local storage or Git; temporary setup key shown only in UI memory. No new external service.

Rollback SQL fixture tests passed default optional access, rejecting password-only owner policy updates, accepting verified owner changes, denying AAL1 JWT even when session is elevated, requiring staff under staff policy, rejecting staff policy updates, and legacy AAL1 session denial. Real TOTP enrollment, challenge and recovery have not been exercised with a physical authenticator; keep policy optional until tested. Existing password leak and pg_net advisor warnings not resolved by this release. No security certification.
