# TechStore PWA 2.0 — متجر وإدارة محل

نسخة أولية محلية، عربية وإنكليزية، قابلة للتجربة ببيانات جاهزة. جميع الأسعار والمواصفات والسجلات أمثلة تعليمية وليست أسعار سوق أو عروضاً حقيقية؛ راجع المورد والمصنع.

## التشغيل
1. فك الضغط عن الملف ZIP وافتح مجلد techstore-v2.
2. شغّل `python -m http.server 8080` من المجلد (يتطلب Python).
3. افتح `http://localhost:8080` في متصفح حديث.
4. لتثبيت PWA على الموبايل انشر المجلد على استضافة HTTPS. أندرويد: قائمة Chrome > تثبيت التطبيق. iOS: Safari > مشاركة > إضافة إلى الشاشة الرئيسية.

يمكن فتح ملف المعاينة HTML المنفصل دون خادم في متصفح يسمح بملفات HTML المحلية. هذا الملف ليس تطبيق PWA مستقلاً للتثبيت، وقد يقيّد المتصفح التخزين المحلي عند فتح ملف مباشرة.

## محتوى التجربة
- 28 منتجاً، 8 فواتير نموذجية، 5 تذاكر صيانة، 2 كفالة، 4 أدوار موظفين، مصاريف وحركة مخزون وطلب متجر وعملاء تجريبيون.
- واجهة الإدارة: لوحة إحصائيات، الطلبات، المخزون، حركات المخزون، المقارنة، التجميع، نقطة البيع، المحاسبة، الصيانة، الكفالات، الموظفون، العملاء، التقارير، الإشعارات، الإعدادات.
- واجهة المتجر: كتالوج وبحث وفئات، مواصفات، مفضلة، سلة، إتمام الطلب، تتبع الطلب والصيانة، المساعدة.
- اختر زر واجهة المتجر / لوحة الإدارة في الأعلى للتبديل. اختبر الأدوار بواسطة القائمة في الأعلى. هذه ليست صلاحيات آمنة ولا تسجيل دخول.
- جرّب طلب المتجر O-DEMO-100 باستخدام رقم الهاتف الوهمي 0000000000. تأكيد الطلب يخصم المخزون وينشئ فاتورة غير محصلة. يمكن تسجيل التحصيل من المحاسبة.
- لتجميع جهاز، اختر ميزانية (مثلاً 800 دولار) واضغط اقتراح تجميعة. الفحص مبدئي ويغطي المقبس ونوع الذاكرة وحجم اللوحة وقدرة الطاقة والحاجة لكرت شاشة، ولا يغطي كل متطلبات BIOS أو التبريد أو التوصيلات أو الأبعاد. ليس ترتيباً لأفضل أداء.
- أدخل سعر صرف يدوي (ليرة سورية لكل دولار) من الإعدادات قبل التحويل إلى الليرة. الأسعار الأساسية محفوظة بالدولار، ولا يتم جلب أسعار صرف حية.
- النسخ الاحتياطي تصدير JSON واستعادة محلية. التقارير تصدير CSV للفواتير. ابدأ ببيانات فارغة من الإعدادات عند الحاجة بعد أخذ نسخة احتياطية.

## الحدود وما يلزم قبل التشغيل التجاري
- بيانات المتصفح غير مشفرة، غير متزامنة وغير محمية ضد التلاعب. لا تدخل بيانات عملاء حقيقية. لا يوجد خادم أو مصادقة أو صلاحيات أمنية أو بوابة دفع أو نسخ احتياطي سحابي.
- الدفع عند الاستلام والتحويل اليدوي سجلات فقط. واتساب يفتح رابطاً مع رسالة معدة يدوياً، ولا يرسل رسائل تلقائياً. الإشعارات محلية، ولا يوجد Web Push من خادم.
- الحسابات مبسطة: لا يوجد دفتر قيود مزدوج أو معالجة ضرائب أو مرتجعات أو تسوية محاسبية. الصيانة تعرض تكلفة تقديرية ولا ترحلها آلياً إلى المبيعات. لا يوجد إلغاء لفاتورة مؤكدة أو طلب مؤكد.
- العمل دون اتصال بعد تحميل ملفات PWA وتفعيل Service Worker في متصفح داعم. لا يوجد مزامنة طلبات بين أجهزة مختلفة.
- الفحص المنفذ: صياغة JavaScript واختبار منطق أولي ببيئة DOM محاكاة، عرض الأقسام والتهيئة والتجميع والسلة واللغة. تعذر اختبار المتصفح الفعلي بسبب قيود البيئة؛ اختبر التثبيت والطباعة وكل مسارات البيع على جهازك قبل الاعتماد.
